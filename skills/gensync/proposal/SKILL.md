# GenSync Proposal

Turn messy scope notes into a tight proposal a founder can say yes to. Read
`../CONTEXT.md` first for services, proof, and voice.

## Input
Ask for (or infer from notes): the prospect, their goal/launch, what they need
(film / site / brand / paid / system), timeline, and any budget signal.

## Output structure (keep it one page)
1. **What you're launching** — restate their goal in their words, one line.
2. **What we'll build** — the specific pieces (map to CONTEXT.md services), built
   together so page/film/deck say the same thing.
3. **Proof** — the single closest case study + one hard number (50M+ impressions,
   3-month runway, etc.).
4. **How it works** — "Bring the messy notes. We turn them into the first useful
   version." Phases + rough timeline.
5. **Investment** — frame as a launch system, **no hard number in writing**;
   "quoted after we agree scope on a working call."
6. **Next step** — the Calendly link: https://calendly.com/manish-gensync/30min

## Rules
- Voice = direct, founder-to-founder, outcome-first. No buzzwords, no moodboards.
- Never invent proof or numbers not in CONTEXT.md.
- The CTA is always the working call, never a price over text/email.
